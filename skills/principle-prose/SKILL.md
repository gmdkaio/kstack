# prose

- short declarative sentences. say what changed and what is left, nothing else.
- no filler openers or closers, no em dashes, no "it's not X, it's Y", no lists of three for rhythm.
- plain words. name things by what the reader knows, not by how the system is built.
- run the `humanizer:humanizer` skill on anything people will read: docs, handoffs, commit bodies, UI copy.
- tone, language and house style beyond this are the user's. read them from the project `CLAUDE.md` and the user's own `CLAUDE.md`.
