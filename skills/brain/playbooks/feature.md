# feature

1. restate the goal in one line.
2. settle the scope. run `kstack:blindspots` if it isn't settled.
3. plan the smallest version. write down what is out.
4. build.
5. verify the real thing (`kstack:principle-prove-it`). a feature with a UI runs the project's verify skill and its ux checks.
6. lean pass: list what was added beyond the request and delete what isn't needed.
7. review. a new feature or a shared signature change gets `kstack:reviewer` on the final commit (`kstack:principle-delegate`). anything smaller does not.
8. close (`kstack:close`).
