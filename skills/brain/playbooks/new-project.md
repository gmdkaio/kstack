# new-project

1. restate the idea in one line.
2. run `kstack:shape`. it ends with an approved `design.md`. nothing is built before that.
3. `kstack:setup` if the project has no `## kstack` section.
4. build the first version the way the `feature` playbook says, from its branch step on: the design's first version is the scope and its plan is the build order.
5. close (`kstack:close`).
